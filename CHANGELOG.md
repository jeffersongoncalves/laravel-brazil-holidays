# Changelog

All notable changes to `laravel-brazil-holidays` will be documented in this file.

## 1.0.0 - 2026-10-11

Initial release: Brazilian national holidays per year (incl. Consciência Negra from 2024), optional Carnival/Corpus Christi, extra state/municipal holidays via config, isHoliday/isBusinessDay/addBusinessDays, pure-PHP Easter.
